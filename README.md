One original word — **quockerwodger** — the first word that came to mind, entered in make.fun's "One Word, First Thought" bounty. A quockerwodger is a politician who follows the crowd instead of any principle: a puppet nodding whichever way the wind blows. Running `main.py` writes exactly that word, plus a trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
python3 main.py
```
